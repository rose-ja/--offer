# 算法 Hot 100 秋招 · 两周冲刺大纲

> 目标：两周内恢复并夯实高频题型的解题手感，能独立完成典型简单题和中等题，并在笔试中稳定拿到基础与中档题分数。
> 学习深度：标准。讲解会深入，但每次只解决一个小问题，先建立直觉再总结规律。
> 节奏：建议每天 90 分钟。其中 25 分钟读一篇或复盘，50 分钟独立写 2-3 题，15 分钟订正并记录错误。

## 核心掌握项

完成本课题后，你将能够：

### 一、读题与线性题
- [x] 能够判断连续子数组/子串题是否适合滑动窗口，并完成最长合法窗口和固定长度窗口的典型题。
- [x] 能够完成最短合法窗口，并根据题目中的数值是否单调判断滑动窗口是否适用。
- [x] 能够用哈希表解决“两数之和、异位词、前缀和计数”等题，并解释键和值各自保存什么。
- [ ] 能够从“下一个更大/更小元素”识别单调栈，并完成每日温度、下一个更大元素等常见变形。

### 二、指针、链表与二分
- [ ] 能够在数组题中选择相向双指针或快慢指针，处理有序数组、移除元素和链表环。
- [ ] 能够用虚拟头结点、双指针完成常见链表增删改，并避免断链和空指针错误。
- [ ] 能够根据有序性或答案的单调性写出二分查找，并处理边界、旋转数组和重复值。

### 三、树、图与回溯
- [ ] 能够为二叉树题写出递归函数的含义，并在前序、后序和层序之间正确选择。
- [ ] 能够区分“找一条路径”的回溯与“消耗一个连通块”的 DFS/BFS，正确处理访问标记。
- [ ] 能够在需要最少步数时使用 BFS，并解释队列、层数和 visited 的作用。

### 四、动态规划与限时实战
- [ ] 能够把简单递归改写成 DP：明确状态含义、转移来源、初始值和遍历顺序。
- [ ] 能够在 35 分钟内完成一道典型 Hot 100 中等题，并通过输入、输出、最小样例和边界检查定位错误。

## 两周训练节奏

| 天数 | 主线题型 | 典型 Hot 100 题 | 当天最低完成标准 |
|------|----------|-----------------|------------------|
| 第 1-2 天 | 哈希、双指针、滑动窗口 | LC1、LC3、LC11、LC15、LC438 | 能不看题解写出一题中等窗口题 |
| 第 3 天 | 前缀和、单调栈 | LC560、LC739、LC739 变形复盘 | 能解释状态含义，不只会套代码 |
| 第 4-5 天 | 链表、二分 | LC19、LC141、LC33、LC34 | 能处理空链表和边界下标 |
| 第 6-7 天 | 树、回溯 | LC102、LC98、LC46、LC78 | 能说清递归函数“返回什么” |
| 第 8-9 天 | 图、网格 BFS/DFS | LC200、LC994、LC207 | 能选择 DFS 或 BFS 并说出理由 |
| 第 10-11 天 | 一维、二维 DP | LC70、LC198、LC300、LC1143 | 能从状态定义推导转移 |
| 第 12 天 | 高频错题回炉 | 从前 11 天错题中选 4 题 | 不看旧代码重写 2 题 |
| 第 13 天 | 限时模拟一 | 混合 3 题 | 90 分钟完成并复盘 |
| 第 14 天 | 限时模拟二与查漏 | 混合 3 题 | 总结个人易错点，重做最弱题型 |

## 不在本课题范围内

- 题目只选 Easy 和 Medium；不把 Hard 题作为本课程的教学或练习内容。
- 不追求两周刷完 Hot 100，也不以记住全部题解为目标。
- 不系统学习竞赛算法，如网络流、计算几何、字符串自动机和高阶数论。
- 不覆盖 Java/C++ 语言细节；示例统一使用本仓库已有的 JavaScript 风格。
- 不保证任何陌生中等题都能立即完成；两周结束的标准是高频题型能识别、典型中等题能独立推进并完成。
