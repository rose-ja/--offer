### 正确答案

**第 1 题：** `s = "baa"`，`p = "aa"`。

```text
right = 0：窗口 "b"，未满 2。
right = 1：窗口 "ba"，长度为 2，但计数不匹配。
right = 2：先进入 a，窗口暂时为 "baa"，长度为 3。
           移走 left 指向的 b，窗口变为 "aa"，left 变成 1。
           计数匹配，记录 1。
```

答案是 `[1]`。

**第 2 题：** 以 `s = "cba"`、`p = "ba"` 为例。`right = 2` 时，进入 `a` 后窗口是 `"cba"`，长度为 3。若先比较，窗口长度不等于 2，不会记录；随后移走 `c` 得到合法窗口 `"ba"`，但这一轮已经没有再次比较，答案下标 1 被漏掉。

所以固定长度窗口的稳定顺序是：

> 右端进入 -> 超长则左端离开 -> 长度刚好等于目标长度时比较。

**第 3 题：** LC3 缩窗的目标是“消除重复”，并不关心固定长度。比如窗口 `"abb"` 只移走 `a` 后仍是 `"bb"`，要继续移动；LC438 的目标是保持长度，长度每次最多多 1，因此移走一个即可。

## 今天换一个目标：从“最长”变成“最短”

LC209：给你一个**全是正整数**的数组 `numbers` 和一个目标值 `target`，找出和至少为 `target` 的最短连续子数组长度；不存在则返回 0。

例子：

```text
target = 7
numbers = [2, 3, 1, 2, 4, 3]
答案 = 2
原因：连续片段 [4, 3] 的和为 7，长度为 2。
```

还是一把尺子，只是这次尺子里装的是数字：

```text
2  3  1  2  4  3
^-----------^
当前和达到目标后，尺子不是继续变长，而是要尽量变短。
```

## 两条规则变了哪一条？

先回忆：

- LC3：出现重复，窗口不合法，才缩小。目标是保留尽量长的合法窗口。
- LC438：窗口长度超了，立即缩小。目标是保持固定长度。

LC209 的目标是**最短**的合法窗口，所以规则是：

1. 右端不断加入数字，让窗口总和增加。
2. 只要总和已经 `>= target`，当前窗口就已经合格。此时立刻记录长度，并尝试从左边移走数字，让它更短。
3. 移走到总和 `< target` 为止，继续移动右端找下一段。

一句话记忆：

> 想找最长合法窗口：不合法才缩。想找最短合法窗口：合法就缩。

## 手工走一遍

`target = 7`，`numbers = [2, 3, 1, 2, 4, 3]`。

先把右端往右放，直到总和首次达到 7：

```text
窗口 [2, 3, 1, 2]，总和 8，长度 4，已经合格。
```

既然已经合格，就不要急着继续加右端，而是从左边尝试缩小：

```text
记录长度 4。
移走 2 后，窗口 [3, 1, 2]，总和 6，不再合格，停止缩小。
```

继续右端加入 4：

```text
窗口 [3, 1, 2, 4]，总和 10，长度 4，合格，记录 4。
移走 3 -> [1, 2, 4]，总和 7，仍合格，记录 3。
移走 1 -> [2, 4]，总和 6，不合格，停止。
```

最后右端加入 3：

```text
窗口 [2, 4, 3]，总和 9，合格，记录 3。
移走 2 -> [4, 3]，总和 7，仍合格，记录 2。
移走 4 -> [3]，总和 3，不合格，停止。
```

最短答案是 2。

你可以把这个过程理解成：右端负责“攒够”，左端负责“去掉多余”。只要已经攒够，就必须让左端工作，否则会漏掉更短的答案。

## 为什么题目强调“正整数”？

这是 LC209 能使用滑动窗口的根本原因。

因为所有数字都是正数：

- 右端加入一个数字，总和只会变大或不变（本题中一定变大）。
- 左端移走一个数字，总和只会变小。

因此，当窗口总和已经小于 `target` 时，再继续移走左边元素只会更小，没有意义；当总和已经达到 `target` 时，尝试移走左边元素才可能得到更短答案。

如果数组允许负数，这种方向感会消失：加入一个负数可能让和变小，移走一个负数反而让和变大。那时“总和不够就扩大、总和够了就缩小”不能保证不漏答案，需要用前缀和等别的方法。

例如：

```text
numbers = [2, -1, 2]
```

右端移动时，总和可能从 2 变为 1，再变为 3，不再单调增加。现在不用解决这类题，只要先记住：**LC209 的窗口解法依赖数组全为正数。**

## 可直接运行的代码

```js
/**
 * 返回和至少为 target 的最短连续子数组长度。
 * 仅适用于 numbers 全为正整数的情况。
 *
 * @param {number} target
 * @param {number[]} numbers
 * @returns {number}
 */
function minSubArrayLen(target, numbers) {
  if (!Number.isFinite(target) || target <= 0 || !Array.isArray(numbers)) {
    return 0;
  }
  if (numbers.length === 0 || numbers.some((number) => !Number.isFinite(number) || number <= 0)) {
    return 0;
  }

  let left = 0;
  let windowSum = 0;
  let shortestLength = Number.POSITIVE_INFINITY;

  for (let right = 0; right < numbers.length; right += 1) {
    windowSum += numbers[right];

    // 已经达标时持续收缩，不能漏掉同一 right 下更短的合法窗口。
    while (windowSum >= target) {
      shortestLength = Math.min(shortestLength, right - left + 1);
      windowSum -= numbers[left];
      left += 1;
    }
  }

  return shortestLength === Number.POSITIVE_INFINITY ? 0 : shortestLength;
}

console.log(minSubArrayLen(7, [2, 3, 1, 2, 4, 3])); // 2
console.log(minSubArrayLen(4, [1, 4, 4])); // 1
console.log(minSubArrayLen(11, [1, 1, 1, 1, 1, 1, 1, 1])); // 0
console.log(minSubArrayLen(7, [])); // 0
```

## 只盯住 `while` 里的三行

```js
while (windowSum >= target) {
  shortestLength = Math.min(shortestLength, right - left + 1);
  windowSum -= numbers[left];
  left += 1;
}
```

顺序不能乱：

1. 先记录答案。此时窗口还合格。
2. 再从总和中减掉左端要离开的数字。
3. 最后移动 `left`，让下标与窗口内容保持一致。

如果先移动 `left` 再记录，长度会少算一个；如果只减总和却忘了 `left += 1`，窗口内容和下标会不一致。
