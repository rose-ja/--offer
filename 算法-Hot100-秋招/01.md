# 从 LC3 开始：用一把会滑动的尺子找最长不重复子串

> 前置知识：会写 `for` 循环，知道 `Map` 可以按“键 -> 值”保存数据。
> 难度：入门
> 预计阅读时间：20 分钟，随后独立写题 25 分钟。

## 先只看题目，不想算法

LC3：给你一个字符串，找出其中**没有重复字符的最长连续片段**，返回它的长度。

例如：

```text
输入："abcabcbb"
答案：3
原因：最长的不重复连续片段可以是 "abc"
```

先注意三个词：

- **连续**：我们找的是一段挨在一起的字符，不能跳着选。
- **最长**：不是找到一个合法片段就结束，而是要比较所有可能。
- **不重复**：同一个字符在这段里最多出现一次。

先别背“滑动窗口”这个名字。你只要把字符串想成一排格子，然后拿一把尺子框住其中一段：

```text
a  b  c  a  b  c  b  b
^--------^
      当前尺子框住 "abc"
```

这把尺子有两个端点：左端 `left` 和右端 `right`。题目要我们找到一把**内容不重复且尽量长**的尺子。

## 为什么不能每一段都试？

最直接的想法是：从每个位置出发，向右不断扩展，检查这段有没有重复。

`n` 个字符大约有 `n * n / 2` 段连续片段。字符串一长，重复检查会很慢。

但这题有一个很好的性质：当我们把右端往右移动，只有**新进来的那个字符**可能造成重复。原来那段如果没有重复，之前的字符不会突然自己重复。

所以不需要每次从头检查整把尺子，只要记住：尺子里每个字符出现了几次。

这就是 `Map` 的工作：

```text
当前窗口是 "abc"
Map 记录：a -> 1，b -> 1，c -> 1
```

## 规则只有两条

每次让右端 `right` 向右走一步，把一个新字符放进尺子里。

1. 新字符没有重复：尺子仍然合法，看看它是不是目前最长。
2. 新字符重复了：左端 `left` 一直右移，把左边离开的字符从统计中减掉，直到重复消失。

关键点是：**右端只往右，左端也只往右，谁都不回头。**

例如处理 `"abba"`：

```text
第 1 步：右端放入 a，窗口 "a"，没有重复。
第 2 步：右端放入 b，窗口 "ab"，没有重复。
第 3 步：右端放入 b，窗口 "abb"，b 重复了。
        左端移走 a，窗口 "bb"，还是重复。
        左端再移走第一个 b，窗口 "b"，恢复合法。
第 4 步：右端放入 a，窗口 "ba"，没有重复。
```

答案是 2。这里必须连续移动左端两次，因此代码必须使用 `while`，不能只写一次 `if`。

## 把上面的过程翻译成代码

先读注释，再看代码。变量名刻意写得长一些，目的是让你知道每个值在保存什么。

```js
/**
 * 返回不含重复字符的最长连续子串长度。
 *
 * @param {string} text
 * @returns {number}
 */
function lengthOfLongestSubstring(text) {
  // LeetCode 保证输入是字符串；这里额外保护空值，便于本地练习。
  if (typeof text !== 'string' || text.length === 0) {
    return 0;
  }

  // 记录当前窗口内每个字符出现的次数。
  const characterCount = new Map();
  let left = 0;
  let longestLength = 0;

  for (let right = 0; right < text.length; right += 1) {
    const enteredCharacter = text[right];
    characterCount.set(
      enteredCharacter,
      (characterCount.get(enteredCharacter) ?? 0) + 1,
    );

    // 右端放入字符后若重复，就从左侧持续移走字符，直到不重复。
    while (characterCount.get(enteredCharacter) > 1) {
      const leavingCharacter = text[left];
      characterCount.set(
        leavingCharacter,
        characterCount.get(leavingCharacter) - 1,
      );
      left += 1;
    }

    // 走到这里时，[left, right] 一定是不重复的合法窗口。
    longestLength = Math.max(longestLength, right - left + 1);
  }

  return longestLength;
}

console.log(lengthOfLongestSubstring('abcabcbb')); // 3
console.log(lengthOfLongestSubstring('bbbbb')); // 1
console.log(lengthOfLongestSubstring('pwwkew')); // 3
console.log(lengthOfLongestSubstring('abba')); // 2
console.log(lengthOfLongestSubstring('')); // 0
```

## 你需要真正看懂的四行

### 1. 右端先把字符放进来

```js
characterCount.set(enteredCharacter, (characterCount.get(enteredCharacter) ?? 0) + 1);
```

`?? 0` 的意思是：这个字符以前没出现过时，把它当作 0 次；然后加 1。第一次进入的 `a` 会得到 `a -> 1`，第二次进入才会得到 `a -> 2`。

### 2. 为什么只检查新进来的字符？

进入新字符之前，窗口已经没有重复。现在唯一发生的变化是“多了 `enteredCharacter`”。所以若出现重复，只可能是它造成的。

例如窗口原来是 `"ab"`，新进来 `b` 后才变成 `"abb"`。不需要扫描 `a`，只检查 `b` 的次数是否大于 1。

### 3. 为什么离开的字符要减 1？

左端右移等于把左侧字符从尺子里拿走。窗口如果从 `"abb"` 变为 `"bb"`，离开的是 `a`，因此 `a` 的次数从 1 变为 0；再从 `"bb"` 变为 `"b"`，离开第一个 `b`，`b` 的次数才从 2 变回 1。

`Map` 里的数据必须始终对应当前尺子里的内容，否则下一次判断一定会错。

### 4. `right - left + 1` 为什么是长度？

下标是从 0 开始的。窗口 `[2, 4]` 包含下标 `2、3、4`，一共 3 个元素：

```text
4 - 2 + 1 = 3
```

所以区间长度永远是“右端下标减左端下标再加一”。

## 用 `"abba"` 跟着代码走一遍

| `right` | 新进字符 | 加入后 `characterCount` 中的关键值 | 是否缩左端 | 合法窗口 | 当前答案 |
|---:|---|---|---|---|---:|
| 0 | a | `a: 1` | 否 | `a` | 1 |
| 1 | b | `b: 1` | 否 | `ab` | 2 |
| 2 | b | `b: 2` | 是，移走 `a` 后仍重复，再移走第一个 `b` | `b` | 2 |
| 3 | a | `a: 1` | 否 | `ba` | 2 |

如果你能自己说出第 3 行发生了什么，你已经不是在背模板，而是在控制窗口。

## 这段代码为什么快？

看起来 `for` 里面套了 `while`，但它不是 `O(n^2)`。

- `right` 从左到右只走一遍。
- `left` 也从左到右只走一遍。
- 每个字符最多被右端加入一次、被左端移走一次。

因此总操作次数和字符串长度成正比，时间复杂度是 `O(n)`；`Map` 最多保存不同字符的数量，空间复杂度是 `O(n)`。
