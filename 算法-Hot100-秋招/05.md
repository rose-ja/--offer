## LC49：这次不是“找一个”，而是“分成几组”

LC49「字母异位词分组」：给你一个字符串数组，把由**相同字母和相同次数**组成的字符串放到同一组中，组的顺序不限。

```text
输入： ["eat", "tea", "tan", "ate", "nat", "bat"]
输出： [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

`"eat"`、`"tea"`、`"ate"` 的字符顺序不同，但都有 a、e、t 各一个，所以它们属于同一组。

这题和 LC1 的共同点仍然是 `Map`，但任务发生了变化：

```text
LC1：键是“我要找的某个数字”，值是“它出现的下标”。
LC49：键是“这一类字符串的统一标识”，值是“属于这一类的字符串数组”。
```

## 关键问题：怎样给同类字符串一张相同的身份证？

字符串 `"eat"`、`"tea"`、`"ate"` 原文不一样，不能直接把原字符串当作同一组的键。

但如果把每个字符串里的字母排序：

```text
eat -> aet
tea -> aet
ate -> aet
tan -> ant
nat -> ant
bat -> abt
```

排序后的结果就像一张身份证：

> 两个字符串互为字母异位词，当且仅当它们排序后的字符串相同。

所以：

```text
键：排序后的字符串，例如 "aet"。
值：所有身份证是 "aet" 的原字符串，例如 ["eat", "tea", "ate"]。
```

## 手工走一遍

处理 `["eat", "tea", "tan", "ate"]`：

| 当前字符串 | 排序后的身份证 | `Map` 中是否已有这张身份证 | 操作 |
|---|---|---|---|
| `eat` | `aet` | 没有 | 新建 `aet -> [eat]` |
| `tea` | `aet` | 有 | 追加，变成 `aet -> [eat, tea]` |
| `tan` | `ant` | 没有 | 新建 `ant -> [tan]` |
| `ate` | `aet` | 有 | 追加，变成 `aet -> [eat, tea, ate]` |

循环结束后，`Map` 的所有值就是答案：

```text
[["eat", "tea", "ate"], ["tan"]]
```

## 代码只有一个核心分支

```js
if (!groupsBySignature.has(signature)) {
  groupsBySignature.set(signature, []);
}
groupsBySignature.get(signature).push(word);
```

它的含义是：

1. 第一次看到这张身份证时，先准备一个空组。
2. 无论这一组原来是否存在，都把当前原字符串放进去。

不要写成 `groupsBySignature.set(signature, [word])`。这样遇到第二个同类字符串时，会把旧数组整个覆盖掉，只剩最后一个字符串。

## 可直接运行的代码

```js
/**
 * 将字母种类和次数相同的字符串放进同一组。
 *
 * @param {string[]} words
 * @returns {string[][]}
 */
function groupAnagrams(words) {
  if (!Array.isArray(words) || words.some((word) => typeof word !== 'string')) {
    return [];
  }

  const groupsBySignature = new Map();

  for (const word of words) {
    // 排序后的字符串是字母异位词共享的稳定标识。
    const signature = Array.from(word).sort().join('');

    if (!groupsBySignature.has(signature)) {
      groupsBySignature.set(signature, []);
    }
    groupsBySignature.get(signature).push(word);
  }

  return Array.from(groupsBySignature.values());
}

console.log(groupAnagrams(['eat', 'tea', 'tan', 'ate', 'nat', 'bat']));
// [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]

console.log(groupAnagrams([''])); // [[""]]
console.log(groupAnagrams(['a'])); // [["a"]]
console.log(groupAnagrams([])); // []
```

## 为什么 `Array.from(word)` 后再排序？

`word` 是字符串，字符串本身不能直接调用数组的 `sort()`。`Array.from(word)` 先把它变为字符数组：

```text
"tea" -> ["t", "e", "a"] -> ["a", "e", "t"] -> "aet"
```

因此这一行做了三件事：

```js
const signature = Array.from(word).sort().join('');
```

1. `Array.from(word)`：拆成字符数组。
2. `sort()`：把字符排成相同顺序。
3. `join('')`：拼回可以作为 `Map` 键的字符串。

## 为什么不用数组直接做 `Map` 的键？

看起来可以把排序后的数组 `['a', 'e', 't']` 直接作为键，但 JavaScript 会按“是不是同一个数组对象”判断，而不是按数组内容判断：

```js
['a', 'e', 't'] === ['a', 'e', 't']; // false
```

两个数组内容相同，却是两个不同对象。把它们 `join('')` 变为字符串 `"aet"` 后，字符串按内容比较，才能作为稳定的共同身份证。

## 复杂度怎么判断？

假设一共有 `n` 个字符串，每个字符串平均长度为 `k`：

- 每个字符串排序需要 `O(k log k)`。
- 一共排序 `n` 次，所以时间复杂度是 `O(n * k log k)`。
- `Map` 保存所有字符串及分组，额外空间约为 `O(n * k)`。

这题还有一种“26 个字母计数数组”的写法：不用排序，而是数每个字母的次数。你的项目已有对应实现。当前阶段先把“统一身份证 -> `Map` 分组”的主线写稳；下一篇回顾时再把它和计数数组的写法进行比较。
