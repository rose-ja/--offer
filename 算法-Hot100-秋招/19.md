## LC994：题目问的是“全部腐烂最少要几分钟”

网格中的数字含义：

```text
0：空格子
1：新鲜橘子
2：已经腐烂的橘子
```

每经过 1 分钟，腐烂橘子会让上下左右相邻的新鲜橘子变腐烂。返回让所有橘子腐烂所需的最少分钟数；如果有橘子永远无法腐烂，返回 `-1`。

例如：

```text
初始：       经过 1 分钟：  经过 2 分钟：
[2, 1, 1]    [2, 2, 1]      [2, 2, 2]
```

答案是 2。这里最容易犯的错误是：看到一个橘子就立刻把它产生的新鲜橘子继续处理，导致把“同一分钟发生的传播”错误地算成多分钟或少分钟。

## 为什么必须按层处理？

同一分钟腐烂的橘子应该视为一批：

```text
第 0 分钟：初始所有腐烂橘子
第 1 分钟：它们能直接感染的新鲜橘子
第 2 分钟：第 1 分钟新腐烂的橘子继续感染的橘子
```

这和 LC102 的层序遍历完全同构：

| LC102 | LC994 |
|---|---|
| 当前层节点 | 当前分钟已经腐烂的橘子 |
| 下一层节点 | 下一分钟才会腐烂的橘子 |
| 遍历完一层 | 时间经过 1 分钟 |

所以每处理完一批当前橘子，才把 `minutes` 加 1，并切换到下一批。

## 先数新鲜橘子，再决定是否需要 BFS

初始化时扫描一次网格，同时做两件事：

1. 把所有初始腐烂橘子的坐标放入 `currentLevel`。
2. 统计新鲜橘子数量 `freshCount`。

两个边界情况可以直接处理：

- `freshCount === 0`：没有新鲜橘子，不需要等待，答案是 0。
- `freshCount > 0` 但 `currentLevel` 为空：没有腐烂源，永远无法全部腐烂，答案是 -1。

## 一分钟的完整动作

假设当前分钟开始时：

```text
currentLevel = 这一分钟开始前已经腐烂的所有橘子
nextLevel = []
```

处理 `currentLevel` 中的每个坐标，检查四个方向：

```text
如果邻居是新鲜橘子：
  freshCount -= 1
  立刻标记为腐烂
  放入 nextLevel
```

为什么要“立刻标记”？同一分钟可能有两个腐烂橘子同时挨着同一个新鲜橘子；第一个处理时就标记，第二个看到它已经是 2，就不会重复减少 `freshCount`。

当前层全部处理完后：

```text
minutes += 1
currentLevel = nextLevel
```

这保证 `nextLevel` 中的橘子统一在下一分钟才作为传播源。

## 可直接运行的代码

下面使用当前层 / 下一层数组，避免 `shift()` 每次移动整个数组，也让“分钟 = 层数”直接可见。

```js
/**
 * 返回让所有新鲜橘子腐烂所需的最少分钟数。
 * 输入 grid 会被原地修改：新鲜橘子 1 会变为腐烂橘子 2。
 *
 * @param {number[][]} grid
 * @returns {number}
 */
function orangesRotting(grid) {
  if (!Array.isArray(grid) || grid.length === 0) {
    return 0;
  }

  const columnCount = Array.isArray(grid[0]) ? grid[0].length : 0;
  if (columnCount === 0) {
    return 0;
  }

  const currentLevel = [];
  let freshCount = 0;

  for (let row = 0; row < grid.length; row += 1) {
    const currentRow = grid[row];
    if (!Array.isArray(currentRow) || currentRow.length !== columnCount) {
      return -1;
    }

    for (let column = 0; column < columnCount; column += 1) {
      const cell = currentRow[column];
      if (cell === 1) {
        freshCount += 1;
      } else if (cell === 2) {
        currentLevel.push([row, column]);
      } else if (cell !== 0) {
        return -1;
      }
    }
  }

  if (freshCount === 0) {
    return 0;
  }
  if (currentLevel.length === 0) {
    return -1;
  }

  const rowCount = grid.length;
  const directions = [
    [-1, 0],
    [1, 0],
    [0, -1],
    [0, 1],
  ];
  let minutes = 0;

  while (freshCount > 0 && currentLevel.length > 0) {
    const nextLevel = [];

    for (const [row, column] of currentLevel) {
      for (const [rowOffset, columnOffset] of directions) {
        const nextRow = row + rowOffset;
        const nextColumn = column + columnOffset;

        if (
          nextRow < 0 ||
          nextRow >= rowCount ||
          nextColumn < 0 ||
          nextColumn >= columnCount ||
          grid[nextRow][nextColumn] !== 1
        ) {
          continue;
        }

        // 立刻标记，防止同一分钟的多个来源重复感染同一格。
        grid[nextRow][nextColumn] = 2;
        freshCount -= 1;
        nextLevel.push([nextRow, nextColumn]);
      }
    }

    minutes += 1;
    currentLevel.length = 0;
    currentLevel.push(...nextLevel);
  }

  return freshCount === 0 ? minutes : -1;
}

console.log(orangesRotting([[2, 1, 1], [0, 1, 1], [0, 0, 1]])); // 4
console.log(orangesRotting([[2, 1, 1], [0, 1, 1], [1, 0, 1]])); // -1
console.log(orangesRotting([[0, 2]])); // 0
console.log(orangesRotting([[1, 1], [1, 1]])); // -1
```

## 复杂度：把每个格子和每条边都数一遍

设网格有 `m` 行、`n` 列，总格子数是 `m * n`。

### 1. 初始化扫描

双层循环每个格子一次：

```text
m 行 * n 列 = m * n 次
```

所以初始化是 `O(mn)`。

### 2. BFS 中每个格子会被真正处理几次？

一个新鲜橘子只有在第一次被感染时才满足 `grid[nextRow][nextColumn] === 1`。随后立刻变成 2，因此：

- 每个新鲜橘子最多进入 `nextLevel` 一次。
- 每个初始腐烂橘子只在初始 `currentLevel` 中出现一次。
- 所有 BFS 层合起来，最多处理 `m * n` 个格子。

每个处理过的格子检查 4 个方向：

```text
m * n 个格子 * 4 个方向 = 4mn = O(mn)
```

### 3. 合并成本

初始化和 BFS 是先后执行的两段：

```text
O(mn) + O(mn) = O(mn)
```

不是 `O(mn * mn)`，因为 BFS 没有对每一个初始化格子都重新完整执行一遍；所有 BFS 合起来只消耗每个格子一次。

### 4. 空间复杂度

`currentLevel` 和 `nextLevel` 最坏可能同时保存 `O(mn)` 个坐标，因此辅助空间是 `O(mn)`。输入网格是原地修改，不把它重复计入额外空间；如果使用复制网格或独立 `visited`，则总占用会再多一个 `O(mn)`。

## “最少分钟”为什么 BFS 能保证？

所有初始腐烂橘子同时作为第 0 层来源。第 1 层是距离任意初始腐烂源为 1 的可达格子，第 2 层是距离为 2 的格子，以此类推。

因此一个橘子第一次被放入某一层时，得到的就是它能够被感染的最早时间。BFS 不会先走很远再回头覆盖更短路径；它按距离从小到大处理层。
