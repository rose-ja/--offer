## 一、先把题目翻译成人话

LC128 给一个无序整数数组，要求找出其中最长的“连续整数序列”的长度。

例如：

```text
numbers = [100, 4, 200, 1, 3, 2]
```

虽然数组顺序很乱，但数字：

```text
1, 2, 3, 4
```

是连续的，长度为 4，所以答案是 4。

关键点：题目问的是**数字值是否连续**，不是数组下标是否连续，也不是要找原数组中的连续子数组。

## 二、最慢的做法为什么不够好？

一个直觉做法是：对每个数字，都不断查询下一个数字在不在。

```text
从 1 开始查 2、3、4
从 2 开始查 3、4
从 3 开始查 4
从 4 开始查 5
```

这会重复数同一段序列。长度为 n 的连续序列会产生：

```text
n + (n - 1) + (n - 2) + ... + 1
```

次数约为 `n² / 2`，因此可能达到 `O(n²)`。

我们需要避免“从 2 又数一遍 3、4；从 3 又数一遍 4”。

## 三、唯一关键：只有序列起点才向右数

看连续序列：

```text
1, 2, 3, 4
```

其中只有 1 是起点，因为：

```text
0 不存在
```

2 不是起点，因为 1 存在；3 不是起点，因为 2 存在；4 不是起点，因为 3 存在。

因此，对于任意数字 `value`：

```text
如果 value - 1 不存在，value 才是一段连续序列的起点。
如果 value - 1 存在，value 一定是某段序列的中间或结尾，不从它重新数。
```

这条判断就是本题的贪心规则：

```javascript
if (!numberSet.has(value - 1)) {
  // value 是起点，才开始向右数 value + 1、value + 2...
}
```

它和 LC55 的共同点是：不枚举所有重复路线，只保留或启动真正有价值的状态。

## 四、用一个含重复值的例子手工走

输入：

```text
[100, 4, 200, 1, 3, 2, 2]
```

先放进 `Set`：

```text
{100, 4, 200, 1, 3, 2}
```

重复的 2 自动只保留一份。然后逐个检查集合里的数：

| 当前数字 `value` | `value - 1` 是否存在 | 是不是起点 | 后续连续数字 | 本段长度 |
|---:|---|---|---|---:|
| 100 | 99 不存在 | 是 | 100 | 1 |
| 4 | 3 存在 | 否 | 不从 4 重数 | - |
| 200 | 199 不存在 | 是 | 200 | 1 |
| 1 | 0 不存在 | 是 | 1, 2, 3, 4 | 4 |
| 3 | 2 存在 | 否 | 不从 3 重数 | - |
| 2 | 1 存在 | 否 | 不从 2 重数 | - |

最长长度就是 4。

注意：集合迭代顺序对答案没有影响。即使先看到 4，也会因为 3 存在而跳过；等看到真正起点 1，才会把 1 到 4 完整数出来。

## 五、看似双层循环，为什么仍然是 `O(n)`？

代码里会有外层遍历和内层 `while`：

```text
外层：检查每个不同数字是否为起点。
内层：只有从起点出发，才一直查下一个数字。
```

不要看到两层就立刻写 `O(n²)`。还是用序列 `1, 2, 3, 4` 数实际工作：

```text
外层检查：1、2、3、4 各一次。
内层从 1 出发：查询 2、3、4、5。
内层不会从 2、3、4 再开始，因为它们前一个数字都存在。
```

内层真正沿序列向右走的工作，不会被另一段起点重复使用。每个不同数字至多属于一段连续序列，并且只会被那段序列的唯一起点向右数到一次。

所以可以分开相加：

```text
建 Set：读取 n 个原数组元素，O(n)。
外层：最多检查 n 个不同数字，O(n)。
所有内层 while 合计：每个不同数字至多被向右计数一次，O(n)。
总时间：O(n) + O(n) + O(n) = O(n)。
```

这里不是 `n * n`，因为内层 `while` 并不会为外层的每一个数字完整执行一遍。

`Set` 最多保存 n 个不同数字，因此空间复杂度为：

```text
O(n)
```

## 七、完整 JavaScript 实现

```javascript
function longestConsecutive(numbers) {
  if (!Array.isArray(numbers)) {
    throw new TypeError('numbers 必须是数组');
  }

  for (const value of numbers) {
    if (!Number.isInteger(value)) {
      throw new TypeError('numbers 中的每一项必须是整数');
    }
  }

  const numberSet = new Set(numbers);
  let longestLength = 0;

  for (const value of numberSet) {
    if (numberSet.has(value - 1)) {
      continue;
    }

    let currentValue = value;
    let currentLength = 1;

    while (numberSet.has(currentValue + 1)) {
      currentValue += 1;
      currentLength += 1;
    }

    longestLength = Math.max(longestLength, currentLength);
  }

  return longestLength;
}
```

变量含义不要混：

```text
value：正在判断是否为起点的数字。
currentValue：从起点向右数时，目前数到哪个数字。
currentLength：这一段连续序列已经数了几个数字。
longestLength：所有起点中最长的一段长度。
```

## 八、面试时怎么说

> 我先把所有数字放进 Set，让存在性查询变成平均 `O(1)`。然后遍历 Set 中每个不同数字，只有当 `value - 1` 不存在时，它才是一段连续序列的起点；我才从它开始不断检查 `value + 1`、`value + 2`。这样中间数字不会重复作为起点计数。设原数组长度为 n，建 Set 是 `O(n)`，外层检查每个不同数字一次，所有向右扩展合计也不会重复经过某个不同数字，因此总时间 `O(n)`；Set 需要 `O(n)` 空间。
